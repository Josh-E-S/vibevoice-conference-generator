VibeVoice: A Frontier Open-Source Text-to-Speech Model

VibeVoice generates expressive, long-form, multi-speaker conversational audio from text. It uses continuous speech tokenizers at an ultra-low 7.5 Hz frame rate and a next-token diffusion framework to synthesize up to 90 minutes of speech with up to 4 distinct speakers.

Key features

  • Multi-speaker — up to 4 distinct voices
  • Long-form — up to 90 minutes of audio
  • Natural flow — turn-taking, interruptions, filler words
  • Efficient — 7.5 Hz tokenizers for low compute cost

Architecture

  • Continuous speech tokenizers — acoustic + semantic at 7.5 Hz
  • Next-token diffusion — LLM context + diffusion generation
  • Diffusion head — high-fidelity acoustic output

Models

  • 1.5B — fast inference, great for iteration
  • 7B — higher fidelity, longer generation time
Conference Generator — powered by VibeVoice Runs speech synthesis on Modal GPU workers; script writing via Qwen2.5-Coder-32B.
